## 五、常用命令速查

### 5.1 静态
```bash
file target.so
readelf -h -S -l -d -r target.so
readelf --dyn-syms target.so | grep Java_
strings -a target.so | grep -iE "key|salt|cipher|aes|sm4|frida|assets"
```

### 5.2 capstone 反汇编
```python
import capstone
data = open("target.so","rb").read()
md = capstone.Cs(capstone.CS_ARCH_ARM64, capstone.CS_MODE_ARM)
for i in md.disasm(data[addr:addr+length], addr):
    print(f"{i.address:#x}: {i.mnemonic} {i.op_str}")
```

### 5.3 pyelftools 读重定位 / 符号
```python
from elftools.elf.elffile import ELFFile
elf = ELFFile(open("target.so","rb"))
for sec in elf.iter_sections():
    if sec.name in (".rela.dyn", ".rela.plt"):
        for rel in sec.iter_relocations():
            printf(rel["r_offset"], rel["r_info_type"])
```

### 5.4 Qiling 铁三角
```python
import sys; sys.path.insert(0, r"D:\逆向工具\qiling\qiling-master")
from qiling import Qiling
ql = Qiling([r"D:\逆向工具\qiling\work\target.so"],
            rootfs=r"D:\逆向工具\qiling\rootfs\rootfs-master\arm64_android")
```

### 5.5 IDA headless（大 SO 定点分析）
```bash
idat -A -S"script.py" target.so
```
