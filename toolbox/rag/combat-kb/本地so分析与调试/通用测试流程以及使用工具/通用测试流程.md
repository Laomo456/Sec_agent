# 通用测试流程

> 从拿到 `.so` 到产出，端到端流程。**判据驱动，不举具体实例。**
> 每一步都给出"完成判据"，未达成则不进入下一步。

---

## 0. 总览

```
拿到 .so
  │
  ① 定目标 ──→ ② 静态定面 ──→ ③ 选动态方案 ──→ ④ 动态执行 ──→ ⑥ 产出
                                        └────→ ⑤ 设备端(如需) ─┘
```

| 阶段 | 产出 | 判据 |
| --- | --- | --- |
| ① 定目标 | 要测的六件事（清单）| 能写出"这份 SO 要回答哪几个问题" |
| ② 静态定面 | 接缝 / 壳 / 特征 / 依赖 | 见 `方法/方法.md §3` 判据 |
| ③ 选方案 | 用 unidbg 还是 Qiling | 看是否有 JNI / Java 回调 |
| ④ 动态执行 | 参数 / 密钥 / 明文 / 行为 | 目标函数跑通并返回 |
| ⑤ 设备端 | 真实网络 / 系统调用下的行为 | hook 命中且不崩 |
| ⑥ 产出 | 锚点 / 材料 / 明文 / 绕过 / 依赖 | 见 `目的/目的.md §6` |

---

## ① 定目标（要测什么）

对照 `目的(关键分析)/目的.md §2` 的**六件事**，逐条确认本 SO 要回答哪些：

1. 数据流边界（明文 / 密文 / 签名在哪层）
2. 数据变换（每层做什么变换）
3. 密钥 / 材料来源（静态 / 派生 / 白盒 / 下发）
4. 入口与接缝（hook 锚点）
5. 防护（检测 + 触发时机）
6. 运行时依赖

> **判据**：明确"先答哪几个"，避免无目标地全量分析。

---

## ② 静态定面

按 `方法/方法.md` 执行：

```bash
file target.so
readelf -h -S -l -d -r target.so
readelf --dyn-syms target.so | grep Java_
strings -a target.so | grep -iE "key|salt|cipher|aes|sm4|frida|assets|init"
```

- 得到**接缝清单**（JNI / 导出）+ **特征字符串**（加密 / 检测 / 资源名）+ **壳判定**。
- 用 IDA / capstone 反汇编 `init_array` / `JNI_OnLoad` / 目标函数 → 得到**偏移**。

> **判据**：接缝清单已列全；关键函数地址 / 范围确定。

---

## ③ 选动态方案

| 条件 | 选 |
| --- | --- |
| 有 `JNI_OnLoad` + `RegisterNatives`，需 Java 回调 | **unidbg**（`方法(动态调试)/unidbg本地hook.md`）|
| 纯算法 / 无 JNI 入口 / 需真实 syscall | **Qiling**（`方法(动态调试)/Qiling本地执行.md`）|
| 需真实网络 / 栈回溯 / 系统调用 | **设备端 Frida** |
| 只是反复调参验证 | 本地（unidbg / Qiling）|

> **判据**：能说清"为什么用它"，并知道要补什么（JNI 回调 ↔ 重定位 / TLS / init）。

---

## ④ 动态执行

**通用步骤**（无论 unidbg / Qiling）：

```
1. 加载 SO（映射 + 解析）
2. 补环境
   - unidbg: MyJni 补 Java 回调 + GOT
   - Qiling: 手动重定位 + TLS + pthread_once + init_array
3. hook 目标点（取参 / 返回值）
4. 触发 / 调用目标函数
5. 抄参数、读内存、验证
```

> **判据**：目标函数**跑通并返回**；hook **命中**；关键参数可读。

---

## ⑤ 设备端（如需）

当需要**真实网络 / 系统调用 / 运行时行为**时，用设备端 Frida（见配套手册）：
- 本地验证 key 来源 / 参数格式 → 设备上 hook 网络层。
- 防检测：取完立即 detach，短周期重试。

> **判据**：attach 不崩、hook 命中、拿到目标数据。

---

## ⑥ 产出与验证

| 产出 | 验证判据 |
| --- | --- |
| 锚点清单 | hook 稳定命中 |
| 密钥 / 材料 | 用它**离线解密成功** |
| 明文 | 与协议 / 业务可对上 |
| 绕过 | attach / hook **不再崩** |
| 依赖清单 | 模拟执行**能跑通** |

**硬标准（闭环）**：**变换 A 的结果能被逆向变换 B 还原**（`encode→decode` 回原文）= 环境 / 参数补对了。

---

## 附：流程决策树

```
静态定面
  │
  ├─ 有 JNI 注册？
  │   ├─ 是 → unidbg（补 MyJni）
  │   └─ 否 → Qiling（补重定位/环境）
  │
  ├─ 纯算法 / 无外部依赖？
  │   └─ 本地模拟即可
  │
  ├─ 需要真实网络 / 系统调用？
  │   └─ 设备端 Frida
  │
  └─ 有反调试 / 反注入？
      └─ 先绕检测（一次性过启动；持续则 replace 检测函数）
```
