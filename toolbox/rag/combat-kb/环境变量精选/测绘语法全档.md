# 测绘手册 — 空间搜索引擎语法合集(ZoomEye / Quake / FOFA)

> 用途:公网资产测绘。覆盖 ZoomEye、Quake、FOFA 三大空间搜索引擎语法与 API。
> 各引擎 API Key 见对话记录,勿外泄。

## 第一部分:ZoomEye(钟馗之眼)

### 一、检索基础

- 覆盖设备(IPv4、IPv6)及网站(域名);全局模式匹配 HTTP/SSH/FTP 等协议的 header、body、ssl、title 及其他 banner
- 不区分大小写,分词匹配;`==` 精准匹配(区分大小写)
- 字符串用引号 `"..."` 或 `'...'`;串内引号/括号用 `\` 转义,如 `"a\"b"`、`portinfo\(\)`

### 二、逻辑运算

| 语法 | 说明 | 示例 |
| --- | --- | --- |
| `=` | 包含关键词 | `title="知道创宇"` |
| `==` | 精准匹配(区分大小写) | `title=="知道创宇"` |
| `\|\|` | 或 | `service="ssh" \|\| service="http"` |
| `&&` | 且 | `device="router" && after="2020-01-01"` |
| `!=` | 非 | `country="CN" && subdivisions!="beijing"` |
| `()` | 优先 | `(country="CN" && port!=80) \|\| (country="US" && title!="404 Not Found")` |
| `*` | 模糊 | `title="google*"` |

### 三、地理位置

`country="CN"` / `country="中国"`、`subdivisions="北京"`、`city="changsha"` / `city="长沙"`

### 四、证书搜索(TLS/SSL)

| 语法 | 说明 |
| --- | --- |
| `ssl="google"` | 证书含字符串(提产品/公司名找目标) |
| `ssl.cert.fingerprint="..."` | 证书指纹 |
| `ssl.chain_count=3` | 证书链计数 |
| `ssl.cert.alg="SHA256-RSA"` | 签名算法 |
| `ssl.cert.issuer.cn="..."` | 签发者 CN |
| `ssl.cert.pubkey.rsa.bits=2048` / `ecdsa.bits=256` | 公钥位数 |
| `ssl.cert.pubkey.type="RSA"` | 公钥类型 |
| `ssl.cert.serial="..."` | 证书序列号 |
| `ssl.cipher.bits="128"` / `ssl.cipher.name="TLS_AES_128_GCM_SHA256"` / `ssl.cipher.version="TLSv1.3"` | 套件 |
| `ssl.version="TLSv1.3"` | SSL 版本 |
| `ssl.cert.subject.cn="example.com"` | 持有者 CN |
| `ssl.jarm="29d2..."` / `ssl.ja3s=45094d...` | JA3/JARM 指纹 |

### 五、IP 及域名

| 语法 | 说明 |
| --- | --- |
| `ip="8.8.8.8"` / `ip="2600:3c00::..."` | IPv4/IPv6 |
| `cidr="52.2.254.36/24"` / `/16` / `/8` | 网段 |
| `org="北京大学"` / `isp="China Mobile"` / `asn=42893` | 归属 |
| `port=80` | 端口(暂不支持多端口) |
| `hostname="google.com"` | 主机名 |
| `domain="baidu.com"` | 域名/子域 |
| `icp.number="京ICP备10040895号-40"` / `icp.name="知道创宇"` | 备案 |
| `banner="FTP"` | 非 HTTP 协议报文 |
| `http.header.server="Nginx"` / `http.header.status_code="200"` | HTTP 头 |
| `http.header_hash="27f9..."` / `http.body_hash="84a1..."` | 头/正文 hash |
| `http.body="document"` | HTML 正文 |

## 第二部分:Quake(360 网络空间测绘)

### 一、检索基础

- 默认模糊搜索匹配端口响应(response);中文/空格串建议双引号包裹,避免分词
- 大小写敏感字段用 `==`?Quake 语法:`字段:值` 或 `字段="值"` 均兼容

### 二、核心字段

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `ip` | IP/CIDR/IPv6 | `ip:"1.1.1.1"` / `ip:"1.1.1.1/16"` |
| `is_ipv6` / `is_latest` | 过滤 IPv6 / 最新 | `is_ipv6:"true"` |
| `port` | 端口/范围 | `port:"80"`、`port:[80 TO 1024]`、`port:[* TO 80]` |
| `ports` | 多端口(主机模式) | `ports:"80,8080,8000"` |
| `transport` | tcp/udp | `transport:"tcp"` |
| `asn` / `org` | 自治域 | `asn:"12345"`、`org:"No.31,Jin-rong Street"` |
| `hostname` / `domain` | rDNS / 域名 | `domain:"360.cn"`、`domain:*.360.cn` |
| `os` | 操作系统 | `os:"Windows"` |
| `service` / `services` | 服务名 | `service:"http"`、`services:"rtsp,https,telnet"` |
| `app` / `app_version` | 产品 | `app:"Apache"`、`app_version:"1.2.1"` |
| `response` | 服务原始响应 | `response:"奇虎科技"`、`response:"220 ProFTPD 1.3.5a Server"` |
| `cert` | 证书字符串 | `cert:"360.cn"`、`domain:"XXX.com" AND cert:"XXX\.com"` |
| `catalog` / `type` / `level` | 应用类别/类型/层级 | `catalog:"IoT物联网"`、`type:"防火墙"`、`level:"应用业务层"` |
| `vendor` | 厂商 | `vendor:"Sangfor深信服"` |
| `country` / `country_cn` | 国家 | `country:"CN"`、`country_cn:"中国"` |
| `province(_cn)` / `city(_cn)` / `district` | 省市县 | `province_cn:"四川"`、`city_cn:"成都"`、`district:"朝阳区"` |
| `owner` / `isp` | 归属/运营商 | `owner:"tencent.com"`、`isp:"联通"` |
| `img_tag` / `img_ocr` | 图片 | `img_tag:"webcam"`、`img_ocr:"admin"` |
| `sys_tag` | 场景 | `sys_tag:"CDN"`、`sys_tag:"卫星互联网"` |

### 三、HTTP 专项字段

`status_code:200`、`http_path:"/admin"`、`title:"后台"`、`meta_keywords:"网络安全"`、`server:Nginx`、`service.http.server.keyword:"Apache/2.4.29"`、`favicon:"md5"`、`host:"google.com"`、`html_hash:"md5"`、`headers:"ThinkPHP"`、`body:"奇虎"`、`robots_hash`、`sitemap`、`cookie_simhash`、`dom_tree.key:"html,head,body"`、`script_function:"func1"`、`script_variable:"csrfToken"`、`css_class`、`css_id`、`url_load:"/bim/"`、`icp:"京ICP备08010314号"`、`copyright`、`mail:"@163.com"`、`page_type:"登录页"`、`iframe_url`、`iframe_hash`、`domain_is_wildcard:true`、`is_domain:true`、`icp_nature:"企业"`、`icp_keywords`、`_exists_:service.http.icp`

### 四、协议专项(节选)

- **ftp**:`service.ftp.is_anonymous:true`
- **ssh**:`service.ssh.server_keys.fingerprint:"3c:14:..."`、`service.ssh.ciphers:"aes128-ctr"`
- **snmp**:`service.snmp.sysname:"CableHome"`、`service.snmp.syslocation`
- **docker**:`service.docker.containers.Image:"ubuntu"`、`service.docker.version.Version:"19.03.1"`
- **elastic**:`service.elastic.indices.index:"user"`
- **mongodb**:`service.mongodb.authentication:false`、`service.mongodb.buildInfo.version`
- **modbus**:`service.modbus.UnitId:1`、`service.modbus.DeviceIdentification:"Schneider Electric"`
- **s7**:`service.s7.Name_of_the_PLC:"E40"`、`service.s7.Module:"6ES7"`
- **smb**:`service.smb.ServerDefaultDialect:"SMB 3.0"`、`service.smb.Authentication:disabled`
- **tls**:`tls_sha256:"2ed1..."`、`tls_SPKI:"ff9e..."`、`tls_issuer_CN:"OV SSL"`、`tls_subject_CN:"baidu.com"`、`tls_SN:"3225..."`、`browser_trusted:true`

### 五、Quake API(HTTP)

- 认证:`X-QuakeToken: {API-Key}` Header;POST 需 `Content-Type: application/json`
- 端点:
  - `GET /api/v3/user/info` 用户信息
  - `GET /api/v3/filterable/field/quake_service` 可筛字段
  - `POST /api/v3/search/quake_service` 实时查询(小批量)
  - `POST /api/v3/scroll/quake_service` 深度查询(分页 id 5 分钟有效,翻到 data 空为止)
  - `POST /api/v3/aggregation/quake_service` 聚合(最多 2 字段)
  - `POST /api/v3/query/similar_icon/aggregation` favicon 相似(参数 favicon_hash/similar/size)
  - 主机数据同构:`/quake_host` 系列
- 请求体:`{"query": "...", "start": 0, "size": 10, "ignore_cache": false, "latest": true}`(付费可加 start_time/end_time,UTC)
- 返回:`code=0 成功`;`meta.pagination.total` 总数
- 错误码:q3004 验证码 / q3005 限速 / q3007 积分不足 / u3009 缺参 / u3010 类型错 / q3015 语法错 / q3017 字段不支持
- 积分:1 条资产 = 1 积分;月度积分优先。注册用户免费 API 5 次/月,实名 +5,高级 10,终身 20
- 免费/注册用户可用字段:ip, port, hostname, transport, asn, org, service.name, location.country_cn/province_cn/city_cn, service.http.host/title/server
- 会员额外:time, service.response, service.cert, components.*, location.*(英文/isp), service.http.body, service.http.favicon.hash, domain, status_code 等

### 六、Quake CLI / MCP

- CLI:`quake init apikey` → `quake search 'query' -t ip,port,title`、`quake host 1.2.3.4/24`、`quake domain 360.cn`、`quake honeypot <ip>`
- MCP:端点 `https://quake.360.net/mcp/`,Header `X-QuakeToken`;工具 `quake_service_data` / `quake_service_aggregation`

## 第三部分:FOFA

### 一、API 接口

- 端点:`GET https://fofa.info/api/v1/search/all`
- 认证:Query 参数 `key={API_KEY}`
- 参数:

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `qbase64` | 是 | base64 编码后的查询语法 |
| `fields` | 否 | 返回字段,默认 host,ip,port |
| `page` | 否 | 页码,默认 1 |
| `size` | 否 | 每页条数,默认 100,最大 10000 |
| `full` | 否 | true = 搜全部历史(默认近一年) |
| `r_type` | 否 | json |

- 响应:`{"error":false,"size":总数,"page":1,"mode":"extended","query":"...","results":[[...]...]}`;错误时 error=true, errmsg 带错误码,如 `[820031] F点余额不足`
- curl 示例:
  `curl -X GET "https://fofa.info/api/v1/search/all?key=KEY&qbase64=dGl0bGU9ImJpbmci"`

### 二、字段附录(权限分级)

- 免费:ip, port, protocol, country, country_name, region, city, longitude, latitude, asn, org, host, domain, os, server, icp, title, jarm, header, banner, cert, base_protocol, link, cert.issuer.org/cn, cert.subject.org/cn, tls.ja3s, tls.version, cert.sn, cert.not_before/not_after, cert.domain, status_code
- 个人版+:header_hash, banner_hash, banner_fid
- 专业版+:cname, lastupdatetime, product, product_category
- 商业版+:product.version, icon_hash, cert.is_valid, cname_domain, body, cert.is_match, cert.is_equal
- 企业会员:icon, fid, structinfo
- 注意:含 cert/banner 时 size 最大 2000;含 body 时 size 最大 500

### 三、账户与配额

- `GET https://fofa.info/api/v1/info/my` 查账户:fofa_point(F 点)、remain_free_point(网页免费点)、remain_api_query(API 查询次数)、remain_api_data(API 数据条数)
- API 查询消耗 F 点;免费账户 API 次数为 0 时无法调用(实测报 [820031] F点余额不足)

## 第四部分:dsh(DeepSeek Harness)指纹专项

### 一、Web UI 特征(实测 v0.1.0-rc.6,见 Desktop\dsh\dsh指纹报告.md)

- 默认监听 127.0.0.1:3080;启动命令 `dsh --profile web [--host/--port]`
- 响应头:无 Server 头、`Keep-Alive: timeout=5`、chunked
- 首页:`<title>DeepSeek Harness</title>`、`<html lang="zh-CN">`、内嵌 `window.__DSH_BOOT__ = {...}`(rev + entries 插件清单 `/plugins/@deepseek-ai/dsh-*/client.js?rev=<12hex>`)
- SPA fallback:任意未知路径返回 200 + 同一份首页 HTML
- 资源:`/manifest.webmanifest`、`/favicon.svg`(鲸鱼 SVG)、`/assets/vendor-{8hex}.js`
- WS 端点:`/api/events.host`、`/api/events.mux`(Upgrade → 101);HTTP:`/api/respond`;API_PATH=/api

### 二、公网测绘语法

| 引擎 | 语法 |
| --- | --- |
| ZoomEye | `title="DeepSeek Harness"` / `http.body="window.__DSH_BOOT__"` / `port=3080 && title="DeepSeek Harness"` |
| Quake | `body:"window.__DSH_BOOT__"` / `title:"DeepSeek Harness"` / `port:3080 AND title:"DeepSeek Harness"` |
| Fofa | `body="window.__DSH_BOOT__"` / `title="DeepSeek Harness"` |

验证三步:① title + `__DSH_BOOT__`;② 乱写路径仍 200 且 HTML 与首页一致;③ `/api/events.host` WS Upgrade → 101。
