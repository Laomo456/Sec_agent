# 百度引擎搜索 —— 风控机制与自动化实战

> 一句话结论：**百度能自动化，但必须"真人姿势"** —— 用 CDP 复用真实浏览器 + 在首页搜索框里逐字敲入回车。
> 任何"自己拼 `/s?wd=` 直接裸请求"的做法，都会在第 2~3 次被墙。
>
> 实测环境：Windows 11 / Edge 154.0.4258.53（CDP 9222）/ Playwright 1.60 + Python 3.14
> 实测日期：2026-10-08　　工作目录：`C:\Users\20751\Desktop\Iot设备收集\`

---

## 一、三条铁律（先看这个）

| 必须 | 为什么 | 实测证据 |
|---|---|---|
| **用 CDP 复用真实浏览器** | 真人会话有完整 Cookie（`BAIDUID/BIDUPSID/BA_HECTOR/BDORZ…`）、真指纹、真交互历史，风控不拦 | CDP 接管后连发 2 条，**2/2 通过、各 9 条结果**；同样查询在 Playwright 干净 context 里 0/2 |
| **走首页搜索框逐字敲入** | 浏览器自己生成的 URL 带一次性票据（`rsv_t`/`rsv_pq`），比自己拼的参数完整 | 拼 URL：偶发风控；搜索框：稳定通过 |
| **每个 cookie 罐只发 1 次**（非 CDP 时） | 同一 context 第 2 次请求必被墙 | `E1` 同一 context 连发：`#1 正常✅ #2 验证码❌ #3 验证码❌`；`E2/E3` 每条换新 context：**6/6 全通** |

## 二、风控三层（逐层实测排除）

### 第 1 层：cookie 罐复用

```
E1) 同一 context 连发 3 条 → #1 ✅  #2 ❌  #3 ❌
E2) 每条换全新 context    → #1 ✅ #2 ✅ #3 ✅
E3) 再来一轮              → #1 ✅ #2 ✅ #3 ✅   （6/6）
```

**结论**：同一个 cookie 罐的第 2 次请求就弹 `wappass` 验证码。

### 第 2 层：高级算子？—— 排除

| 查询 | 结果 |
|---|---|
| `site:xxx 摄像机`（纯关键词） | ❌ |
| `site:xxx intitle:camera` | ❌ |
| `site:xxx intitle:摄像机` | ❌ |
| `site:xxx 摄像机`（对照，同一条） | ❌ |

连**几分钟前 6/6 全通的同一条纯关键词**也挂 → **不是算子触发的**。

### 第 3 层：IP 级累计配额 ← **真正的主因**

短时间跑量后，**整台机器的出口 IP 被临时拉黑**：换 cookie 罐、换算子、纯关键词、全新 context，**全挂**。
冷却 3 分钟后再探 → **仍未恢复**（实际冷却窗口可能几十分钟起）。

**免费代理换 IP 不可行（实测）**：
- 抓了 30721 条候选（89ip / proxy.scdn.io 等源），抽样 400 条做 **HTTPS** 测活 → 仅 12 条可用
- 拿前 5 条打百度：**0/5 成功**（3 个 timeout、1 个 `ERR_CONNECTION_RESET`、1 个 `ERR_TUNNEL_CONNECTION_FAILED`）
- 免费池的代理大多只能过明文 HTTP，**过不了 HTTPS CONNECT**；且百度配额是 per-IP，要轮换得有很多个 IP

## 三、URL 参数详解（`/s?wd=...`）

从真人搜索框提交的 URL 里抄下来的完整参数集：

```
https://www.baidu.com/s?wd=<query>
  &rsv_spt=1              # 搜索来源标记
  &rsv_iqid=0x<16位hex>   # 会话票据（随机即可）
  &issp=1&f=8&rsv_bp=1
  &rsv_idx=2
  &ie=utf-8
  &tn=baiduhome_pg        # ★ 关键："从首页搜索框发起"标记
  &rsv_enter=1
  &rsv_dl=tb_enter        # ★ 回车提交标记
  &rsv_sug3=20&rsv_sug1=11&rsv_sug7=100&rsv_btype=i&inputT=6246&rsv_sug4=7818
  &pn=<0|10|20>           # 翻页（第 n 页 = (n-1)*10）
```

**`tn=baiduhome_pg` + `rsv_dl=tb_enter` 是"首页搜索框 + 回车"的指纹**，百度对这类请求明显更宽松。
但即便是这套参数，**裸请求也只在第 1 次有效**（见第 1 层）。

### 4.2 Playwright 接管 + 搜索框逐字敲入

```python
import asyncio, random
from urllib.parse import quote_plus
from playwright.async_api import async_playwright

async def baidu_search(query: str, cdp="http://127.0.0.1:9222"):
    async with async_playwright() as pw:
        b = await pw.chromium.connect_over_cdp(cdp)
        ctx = b.contexts[0]                 # 复用真实会话（Cookie 全在）
        page = await ctx.new_page()         # 新标签页，不碰用户正在看的页面
        try:
            await page.goto("https://www.baidu.com/",
                            wait_until="domcontentloaded", timeout=45000)
            await page.wait_for_timeout(2000)
            box = await page.wait_for_selector("#kw", timeout=12000, state="attached")

            # ★ 聚焦要抗造：click 常因浮层/不可见而超时，三级回退
            for fn in (lambda: box.click(timeout=6000),
                       lambda: box.focus(),
                       lambda: page.evaluate("el => el.focus()", box)):
                try:
                    await fn(); break
                except Exception:
                    continue

            await page.keyboard.press("Control+A")
            await page.keyboard.press("Delete")
            await page.keyboard.type(query, delay=45)   # ★ 逐字敲，别用 fill
            await page.wait_for_timeout(700)
            await page.keyboard.press("Enter")
            await page.wait_for_timeout(3000)
            try:
                await page.wait_for_load_state("domcontentloaded", timeout=20000)
            except Exception:
                pass
            await page.wait_for_timeout(3000)
            return page.url, await page.content()
        finally:
            await page.close()              # 只关标签页
        # 不要 b.close()，否则会把用户的浏览器一起关掉
```

## 五、结果解析（关键：`mu` 属性）

百度结果链接是 `/link?url=...` 加密跳转，**别去解析它**。
真 URL 直接写在结果容器的 **`mu="..."` 属性**里，这才是可靠提取点：

```python
import re
pat = re.compile(r'<div[^>]*\bmu="([^"]+)"[^>]*>(.*?)(?=<div[^>]*\bmu="|$)', re.S)
for m in pat.finditer(html):
    url, block = m.group(1), m.group(2)
    tm = re.search(r"<h3[^>]*>(.*?)</h3>", block, re.S)
    title = re.sub(r"\s+", " ", re.sub(r"<[^>]+>", "", tm.group(1))).strip() if tm else ""
    print(url, "|", title)

# 兜底：至少把 mu 都捞出来
urls = re.findall(r'mu="([^"]+)"', html)
```

**验证码判定**：落地 URL 含 `wappass` / `captcha` / `verify` 即是（响应体约 38KB，正常结果页 800KB~1.2MB）。

## 六、失败姿势清单（都踩过）

| 姿势 | 结果 |
|---|---|
| 干净 context 直接拼 `/s?wd=` | 第 1 次可能通，第 2 次必墙 |
| 先访问百度首页"预热"再拼 URL | **反而触发风控**（首页访问会设 cookie 改变会话判定） |
| 每请求换新 context（非 CDP） | 短窗口内 6/6 通，但**配额用完即整段 IP 冷却** |
| 免费代理轮换 IP | 0/5 成功（HTTPS CONNECT 基本不通） |
| `box.fill()` 写字 | 建议改用 `keyboard.type()` 逐字敲 |
| `box.click()` 直接点 | 常 `Timeout 30000ms exceeded`，必须三级回退聚焦 |
| Ctrl+Enter / 其他 tab | 用普通 `Enter` |
| 高频连发 | 加速触发 IP 级冷却 |
