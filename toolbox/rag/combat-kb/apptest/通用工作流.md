# 通用工作流规范

> 适用于 adb shell / frida / 抓包 / 批量操作等所有长耗时任务。

---

## 一、核心原则

### 1.1 分步执行
- 把大任务拆成多个小步骤，每一步可独立验证
- 每一步都有明确的预期结果
- 上一步未通过不要进入下一步

### 1.2 脚本优先
- **任何可能超时（>10s）的操作，先写成脚本再执行**
- 脚本放在任务目录下，命名语义化
- 脚本必须支持断点续传/幂等（已完成的自动跳过）

### 1.3 记录追踪
- 每步留有追踪文件（`.done.txt` / `.progress.txt` / `.downloaded.txt`）
- 脚本意外中断后可从上次断点恢复

---

## 二、通用工作流模板

```
信息收集 → 方案设计 → 环境准备 → 脚本编写 → 分批执行 → 结果验证 → 文档归档
```

### 2.1 信息收集
```powershell
# 例：先摸清环境
adb devices
adb shell getprop ro.product.model
adb shell getprop ro.build.version.sdk
```

### 2.2 方案设计
- 明确目标：要拿什么数据/做什么操作
- 评估风险：超时？阻塞？数据量大？
- 设计脚本：并行度、重试、断点续传
- 确定检验标准：怎么才算成功

### 2.3 环境准备
```powershell
# 创建任务目录
$taskDir = "C:\Users\20751\Desktop\tasks\xxx"
New-Item -ItemType Directory -Path $taskDir -Force
# 创建子目录
"scripts", "data", "logs", "output" | ForEach-Object {
    New-Item -ItemType Directory -Path "$taskDir\$_" -Force
}
```

### 2.4 脚本编写
见下文各场景模板。

### 2.5 执行策略

| 场景 | 策略 | 说明 |
|------|------|------|
| 单次短命令 | 直接跑 | `< 3s，无需脚本 |
| 多次重复 | foreach 循环 | 加 try/catch，记录失败项 |
| 批量/大量 | Start-Job 后台 | 控制并行数，写入追踪文件 |
| 长时阻塞 | Start-Job 后台 | 避免超时丢失进度 |
| 交互式 | 写脚本 + 参数化 | 避免手动交互 |

## 三、ADB Shell 工作流

### 3.1 通用模式
```powershell
# 脚本模板：adb_xxx.ps1
param(
    [string]$DeviceId = "",
    [int]$TimeoutSec = 30,
    [string]$LogFile = ".\logs\adb.log"
)

$adb = if ($DeviceId) { "adb -s $DeviceId" } else { "adb" }

function Invoke-Adb($cmd) {
    $result = & cmd /c "$adb $cmd 2>&1"
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    "$timestamp | $cmd | $result" | Out-File $LogFile -Append
    return $result
}
```

### 3.2 常见操作脚本化

**文本输入**（带重试）
```powershell
# input_text.ps1
param($Text)
$Text.ToCharArray() | ForEach-Object {
    $hex = [int]$_ | ForEach-Object { "0x{0:x2}" -f $_ }
    if ($_ -le 0x7F) {
        adb shell input text $_
    } else {
        adb shell input text ('' + [char]$_)
    }
    Start-Sleep -Milliseconds 50
}
```

**批量按键**
```powershell
# 例：多次滑动搜索
1..10 | ForEach-Object {
    adb shell input swipe 500 1000 500 300
    Start-Sleep -Seconds 2
    $screen = adb shell uiautomator dump /dev/tty 2>$null
    if ($screen -match '没有更多') { break }
}
```

### 3.3 超时保护
```powershell
# 对 adb shell 命令设超时
$job = Start-Job -ScriptBlock { adb shell "长时间命令" }
if (Wait-Job $job -Timeout 30) {
    Receive-Job $job
} else {
    Stop-Job $job; Remove-Job $job
    Write-Warning "命令超时，已终止"
}
```

## 五、抓包/流量分析工作流

### 5.1 Reqable 捕获通用步骤
```
1. 启动 Reqable + 全局代理
2. 设置过滤条件 (host/ path/ method)
3. 执行操作产生流量
4. 从 %APPDATA%\Reqable\capture\ 提取数据
5. 关闭 Reqable 清理规则
```

### 5.2 数据提取模板
```powershell
param(
    [string]$Filter = "",
    [string]$FieldPattern = '"myField":"([^"]+)"',
    [string]$OutputFile = ".\data\extracted.txt"
)

$captureDir = "$env:APPDATA\Reqable\capture"
$files = Get-ChildItem $captureDir -Filter "*res-extract-body*" |
    Sort-Object LastWriteTime -Descending | Select -First 20

$results = @{}
$files | ForEach-Object {
    try {
        $text = Get-Content $_.FullName -Raw -Encoding UTF8
        if ($Filter -and !$text.Contains($Filter)) { return }
        [regex]::Matches($text, $FieldPattern) | ForEach-Object {
            $results[$_.Groups[1].Value] = $true
        }
    } catch { Write-Warning "Parse error: $($_.Name)" }
}

$results.Keys | Sort-Object | Out-File $OutputFile -Encoding UTF8
Write-Host "提取 $($results.Count) 条 -> $OutputFile"
```

## 六、批量操作工作流

### 6.1 标准批量脚本框架
```powershell
param(
    [int]$MaxParallel = 3,
    [string]$InputFile = ".\data\input.txt",
    [string]$TrackerFile = ".\data\.done.txt",
    [string]$LogFile = ".\logs\batch.log"
)

$done = @{}
if (Test-Path $TrackerFile) {
    Get-Content $TrackerFile | ForEach-Object { $done[$_] = $true }
}

$items = Get-Content $InputFile | Where-Object { $_ -and !$done.ContainsKey($_) }

$jobs = @{}
$items | ForEach-Object {
    $item = $_
    while (($jobs.Values | Where-Object { $_.State -eq 'Running' }).Count -ge $MaxParallel) {
        Start-Sleep -Seconds 1
        $jobs.Keys | Where-Object { $jobs[$_].State -eq 'Completed' } | ForEach-Object {
            Receive-Job $jobs[$_] | Out-File $LogFile -Append
            Remove-Job $jobs[$_]; $jobs.Remove($_)
        }
    }
    $job = Start-Job -ScriptBlock { param($i) } -ArgumentList $item
    $jobs[$item] = $job
}

$jobs.Keys | ForEach-Object {
    Wait-Job $jobs[$_] | Out-Null
    Receive-Job $jobs[$_] | Out-File $LogFile -Append
    Remove-Job $jobs[$_]
}
```

### 6.2 常见批量场景

| 场景 | 框架调整 |
|------|----------|
| 批量下载 | 追踪 URL、跳过已完成、限制大小 |
| 批量安装 | 追踪包名、记录失败、重试逻辑 |
| 批量 Hook | 串行执行（避免冲突）、逐个输出 |
| 数据抓取 | 并行 + 防抖、去重、自动分页 |

## 七、结果验证

### 7.1 通用验证脚本
```powershell
param(
    [string]$Dir = ".\output",
    [string]$ExpectedFile = ".\data\expected.txt"
)

Write-Host "=== 验证结果 ==="
$files = Get-ChildItem $Dir -File
Write-Host "产出: $($files.Count) 个文件"

if (Test-Path $ExpectedFile) {
    $expected = (Get-Content $ExpectedFile).Count
    $ratio = [math]::Round($files.Count / $expected * 100, 1)
    Write-Host "预期: $expected, 完成: $ratio%"
}

if (Test-Path ".\logs\batch.log") {
    $errors = Select-String -Path ".\logs\batch.log" -Pattern "FAIL|ERROR|Error"
    if ($errors) { Write-Warning "$($errors.Count) 个错误" }
}
```

### 7.2 断点恢复
```powershell
# 重新运行脚本时会自动跳过已完成的项
# $TrackerFile 记录了所有已完成项
# 删掉 $TrackerFile 可强制全部重跑
```

| 产出 | 说明 |

## 九、速查卡

### 优先级判断
```
直接跑:            单个命令 < 3s
写脚本再跑:         重复操作 / 可能超时 / 有副作用
后台 job:          批量 / 长时阻塞 / 并行
写 .bat 再跑:      frida / 交互式工具链
```

### 追踪文件命名约定
| 用途 | 文件名 | 格式 |
|------|--------|------|
| 已完成项 | `.done.txt` | 每行一个标识符 |
| 已下载 | `.downloaded.txt` | 每行一个 URL |
| 进度 | `.progress.txt` | 当前/总数 |
| 失败项 | `.failed.txt` | 失败项 + 错误信息 |

### 错误处理模板
```powershell
try {
    $item | Out-File $TrackerFile -Append
} catch {
    "$item | $_" | Out-File ".\data\.failed.txt" -Append
    Write-Warning "失败: $item → $_"
}
```
