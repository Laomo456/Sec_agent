## 一、各引擎实测对比(2026-08-31)

### 核心指标对比

| **cn.bing** | 7条 | 71% | 跳转链接(需解析) | `&first=11/21...` | ❌中文Dork无效 | ⭐⭐⭐⭐ |

| DuckDuckGo | 验证码 | — | — | — | 支持site:但反爬 | ❌ |

### 关键发现
1. **百度是最佳中文引擎**：每页48条真实后台，mu属性直接返回真实URL，翻页简单
2. **cn.bing是良好补充**：首页7条中5条真实后台，翻页有新结果
3. **360可用但麻烦**：结果真实但URL需解密跳转
4. **Google Dork最强大**：完整支持site:/intext:，但机房IP全被风控(待住宅IP)
5. **搜狗/神马不可用**：索引太弱，搜狗1条微信文章，神马0条

## 二、百度采集详解(主力引擎)

### 2.1 查询词格式
```
[行业] 管理系统 登录 后台
```
- 不用Dork语法(百度不支持site:/intext:)
- 自然语言关键词组合
- 行业列表(48个): 酒店 医院 学校 物业 物流 仓储 工厂 建筑 房产 装修 家政 健身 食堂 幼儿园 预约 点餐 停车 租车 教务 招生 租赁 会员 售后 监控 门禁 水电 报刊 诊所 药店 超市 餐饮 服装 珠宝 眼镜 茶饮 烘焙 洗衣 保洁 中介 养老 招聘 考勤 合同 财务 发票 采购 供应商 车辆 档案 办公 印刷 客户 人事

### 2.2 翻页参数
```
第1页: &pn=0   第2页: &pn=10  第3页: &pn=20  第N页: pn=(N-1)*10
```
- 每页默认10条，rn=50可调
- 每行业建议翻3页即可(第3页起大量重复)

### 2.3 URL提取(JS代码)
```javascript
// 提取真实URL(mu属性) + 标题
const excludeDomains = ['csdn.net','github.com','gitee.com','cnblogs.com','zhihu.com','sohu.com','cloud.tencent.com','segmentfault.com','51cto.com','oschina.net','infoq.cn','v2ex.com','juejin.cn','bilibili.com','163.com','sina.com','wikipedia.org','microsoft.com','apple.com','douyin.com','kuaishou.com','facebook.com','twitter.com','youtube.com','google.com','bing.com','aliyun.com','huaweicloud.com','jd.com','taobao.com','alibaba.com','qunar.com','booking.com','meituan.com','dianping.com','ctrip.com','elong.com'];
const results = Array.from(document.querySelectorAll('#content_left .result'))
  .map(r => ({
    mu: r.getAttribute('mu'),
    title: (r.querySelector('h3')||{}).textContent || '',
  }));
const filtered = results.filter(r => {
  const url = r.mu;
  if (!url) return false;
  try {
    const x = new URL(url);
    if (excludeDomains.some(d => x.hostname.endsWith(d))) return false;
    if (!/登录|管理|后台|login|admin/i.test(r.title)) return false;
    return true;
  } catch(e) { return false; }
});
return filtered.map(r => r.mu);
```

## 五、Google采集(待风控恢复)

### 5.3 URL提取
```javascript
// Google结果URL在href中，可能是google.com/url?q=REAL或直接URL
const links = page.eval_on_selector_all("a", "els => els.map(e=>e.href).filter(h=>h.startsWith('http'))");
const realUrls = [];
for (const h of links) {
  if (h.includes("google.com/url?q=")) {
    const m = h.match(/[?&]q=(https?%3A%2F%2F[^&]+)/);
    if (m) realUrls.push(decodeURIComponent(m[1]));
  } else if (!h.includes("google.com/search")) {
    realUrls.push(h);
  }
}
```

### 5.5 风控现状(2026-08-31)

## 六、代理与IP问题

### 6.1 已测试的代理
| 代理 | 出口IP | Google搜索 | 说明 |
|------|--------|-----------|------|
| FlClash 7890 | 16.162.47.31(AWS) | 被拦 | 数据中心IP，有IPv6泄露 |
| xray英国 | 51.195.241.196(OVH) | 被拦 | 之前大量请求被标记 |
| 订阅-日本 | 50.7.158.117 | 被拦 | 机房IP |
| 订阅-印度 | 159.65.155.90 | 被拦 | 机房IP |
| 订阅-美国 | 23.237.196.226 | 被拦 | 机房IP |

### 6.2 核心问题
- Google对**机房IP的搜索请求**全域风控
- 反检测浏览器(反指纹)≠ 住宅IP(反风控)
- 浏览器指纹绕过 + 机房IP = 仍然被拦
- **唯一解法：住宅代理 + 反检测浏览器 = 可用**

### 6.3 IPv6泄露问题
- Camoufox默认不禁IPv6 → 浏览器IPv6直连绕过代理
- 修复: `firefox_user_prefs={"network.dns.disableIPv6": True}`
- 验证: `https://api.ipify.org`(IPv4) vs `https://icanhazip.com`(IPv6)

## 七、实操采集流程(推荐)

### 最佳方案：百度(主力) + cn.bing(补充)
```
1. Edge DevTools → 百度 → 每行业搜[行业] 管理系统 登录 后台 → 提取mu属性 → 翻3页
2. Edge DevTools → cn.bing → 同上 → 提取href → 解析跳转
3. 合并去重 → 写入全部结果.txt
4. 等Google风控恢复 → 用Camoufox+住宅代理跑Google Dork
```

### 反检测浏览器使用指南
```python
# Camoufox (Firefox内核)
from camoufox.sync_api import Camoufox
from camoufox import DefaultAddons

with Camoufox(
    headless=True,
    proxy={"server": "http://127.0.0.1:1081"},
    exclude_addons=[DefaultAddons.UBO],
    firefox_user_prefs={"network.dns.disableIPv6": True}
) as browser:
    page = browser.new_page()
    page.goto("https://www.google.com")

# CloakBrowser (Chromium内核)
from cloakbrowser import launch

browser = launch(proxy="http://127.0.0.1:1081")
page = browser.new_page()
page.goto("https://www.google.com")
browser.close()
```
