# 转场类型

> 更新时间：2026-07-28

## 一、Remotion 转场

### 果冻弹性转场（Jelly Transition）
- 组件：`D:\remotion-demo\src\果冻转场.tsx`
- 用途：角色切换时的弹性入场动画
- 原理：指数衰减正弦波，scale ±10%
- 参数：25帧 @30fps = 0.83s（比默认15帧更长，弹性更明显）
- 触发：角色切换时

### 入场动画
- 组件：`D:\remotion-demo\src\入场.tsx`
- 帧数：33帧
- 角色从屏幕外弹入

### 出场动画
- 帧数：45帧

### 退场动画
- 帧数：45帧

## 二、OpenCV 故障转场（Glitch）

- 脚本：`D:\remotion-demo\glitch_gen.py`
- 支持：RGB通道偏移、撕裂、色块、像素排序、色相偏移、扫描线、噪点

## 三、FFmpeg 转场

### 上滑转场（Slide Up）
用于 do_final.py 中 intro → 主内容 的过渡：
```python
ffmpeg -filter_complex "xfade=transition=slideup:duration=0.5:offset=0"
```

### 交叉溶解（Cross Dissolve）
用于总结_转场.mp4 中4个视频段之间的过渡：
```python
ffmpeg -filter_complex "xfade=transition=fade:duration=0.5:offset=..."
```

## 四、FFmpeg concat 直接拼接

- 无转场，简单拼接
- 适合快速预览
- 速度最快（无重编码）
```python
ffmpeg -f concat -safe 0 -i list.txt -c copy merged.mp4
```
