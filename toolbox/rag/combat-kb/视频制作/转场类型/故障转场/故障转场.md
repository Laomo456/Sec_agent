# 故障转场

> 用 Python + OpenCV 像素级处理生成故障转场效果
> 比 Remotion CSS/SVG 渲染强得多（直接操作像素数组）

---

## 快速使用

```bash
cd D:\remotion-demo
python glitch_gen.py 前一段.mp4 后一段.mp4 输出.mp4 [帧数]
```

- `帧数` 默认 30（30fps = 1秒）
- 输出文件包含：前段全部 + 转场 + 后段全部

**示例：**
```bash
python glitch_gen.py public/segments/seg1.mp4 public/segments/seg2.mp4 转场输出.mp4 30
```

## 效果时序

30 帧故障转场的相位设计：

```
帧  0-2   (0-8%)     黑闪
帧  3     (8-12%)    白闪
帧  4-10  (12-35%)   故障高峰期（RGB偏移+撕裂+色块+像素排序）
帧  10    (35-38%)   黑闪
帧  11-17 (38-55%)   持续故障
帧  17-19 (55-62%)   白闪
帧  19-22 (62-73%)   故障收尾
帧  22    (73%)      黑闪
帧  24-27 (82-86%)   白闪
帧  27-30 (86-100%)  抖动收尾
```

- 故障强度按 `sin(π * t)` 包络：0 → 峰值 → 0

## 核心原理

1. `cv2.VideoCapture` 把视频拆成帧（每帧 = 2880×1800×3 的 numpy 数组）
2. 对每帧做 numpy 数组操作：
   - `np.roll` → 通道偏移/撕裂
   - 数组切片 → 提取/替换局部区域
   - `np.argsort` → 像素排序
   - 直接赋值 → 色块/噪点
3. `cv2.VideoWriter` 写回 mp4

### 关键代码片段

**RGB 通道偏移：**
```python
r_ch, g_ch, b_ch = cv2.split(frame)
r_shifted = np.roll(r_ch, -shift, axis=1)   # 红左移
b_shifted = np.roll(b_ch, shift, axis=1)     # 蓝右移
result = cv2.merge([r_shifted, g_ch, b_shifted])
```

**水平撕裂：**
```python
strip = frame[y:y+tear_h, :].copy()
strip = np.roll(strip, offset, axis=1)       # 水平偏移
result[y:y+tear_h, :] = strip                # 覆盖原区域
```

**像素排序：**
```python
row = result[sy, seg_start:seg_end]
gray = cv2.cvtColor(row.reshape(1, -1, 3), cv2.COLOR_BGR2GRAY).flatten()
idx = np.argsort(gray)                       # 按亮度排序
row[:] = row[idx]
```

## vs 其他方案

| 方案 | 效果 | 自由度 | 速度 | 依赖 |
|------|:----:|:-----:|:----:|:----:|
| **Python + OpenCV** ⭐ | 🔥🔥🔥🔥🔥 | 极高 | 中 | opencv-python |
| FFmpeg chromashift | 🔥🔥 | 低 | 快 | ffmpeg |
| Remotion CSS/SVG | 🔥🔥 | 中 | 慢 | node, react |
| 剪映/PR 内置效果 | 🔥🔥🔥🔥 | 中 | — | 桌面软件 |
| Glitch overlay 素材 | 🔥🔥🔥🔥 | 低 | 快 | 素材文件 |

**结论：** Python OpenCV 是自由度和效果最佳平衡点。要更快可用 FFmpeg 滤镜，要更方便用剪映拖。

## 扩展思路

可加效果（代码已预留接口，在 `glitch_frame()` 函数里加新 case 即可）：

- **VHS 磁迹干扰** — 水平抖动 + 色度偏移 + 磁迹横线
- **老电影效果** — 划痕 + 闪烁 + 颗粒噪点
- **热成像伪色** — 根据亮度映射红蓝渐变
- **抽帧/卡顿** — 重复帧 / 跳帧
- **数据损坏花屏** — 逐帧注入二进制噪声
- **RGB 分裂拖尾** — 前几帧残影叠加
- **CRT 滚动撕裂** — 画面斜向/不同步撕裂
