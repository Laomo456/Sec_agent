# 转场类型

> 更新时间：2026-07-28

## 一、Remotion 转场

### 果冻弹性转场（Jelly Transition）
- 组件：`D:\remotion-demo\src\果冻转场.tsx`
- 用途：角色切换时的弹性入场动画
- 原理：CSS spring 弹性动画，scale ±10%
- 参数：15帧 @30fps = 0.5s

### 入场动画
- 组件：`D:\remotion-demo\src\入场.tsx`
- 帧数：33帧
- 角色从屏幕外弹入

### 出场动画
- 组件：`D:\remotion-demo\src\出场.tsx`
- 帧数：45帧

### 退场动画
- 组件：`D:\remotion-demo\src\退场.tsx`
- 帧数：45帧

## 二、OpenCV 故障转场（Glitch）

- 脚本：`D:\remotion-demo\glitch_gen.py`
- 支持效果：
  - RGB 通道偏移
  - 水平/垂直撕裂
  - 彩色损坏块
  - 像素排序
  - 色相偏移
  - 扫描线
  - 花屏噪点

## 三、FFmpeg 转场

### 上滑转场（Slide Up）
用于 do_final.py 中 intro → 主内容 的过渡：
```python
ffmpeg -filter_complex 
  "[0:v][1:v]xfade=transition=slideup:duration=0.5:offset=0"
```

### 交叉溶解（Cross Dissolve）
用于总结_转场.mp4 中4个视频段之间的过渡：
```python
ffmpeg -filter_complex 
  "[0:v][1:v]xfade=transition=fade:duration=0.5:offset=..."
```

## 四、故障转场生成器

### 用法
```bash
python glitch_gen.py 前一段.mp4 后一段.mp4 输出.mp4 [转场帧数]
```

### vs FFmpeg内置
| FFmpeg滤镜 | 能做 | Python优势 |
|:----------|:---:|:----------|
| chromashift | RGB偏移 ✅ | — |
| noise | 噪点 ✅ | — |
| geq | 像素表达式 ⚠️ | Python更灵活 |
| 像素排序 | ❌ 不支持 | ✅ Python直接 |
| 随机撕裂/色块 | ❌ 不支持 | ✅ Python随意 |
