## 一、字幕生成流程

### 整体流程
```
TTS生成MP3 → MP3按文案顺序拼接为audio.wav → VAD检测说话区间 
→ MFCC声纹匹配每段音频在audio.wav中的位置 → 按位置排序生成SRT → 烧录
```


## 二、声纹匹配（MFCC法）

### 原理
使用MFCC（Mel频率倒谱系数）作为音频指纹，通过滑动窗口计算与MP3的相关系数，
找到每个MP3在audio.wav中的最佳匹配位置。

### 代码
```python
def mfcc_voiceprint(y):
    mfccs = librosa.feature.mfcc(y=y, sr=16000, n_mfcc=13, hop_length=160)
    mfccs = (mfccs - np.mean(mfccs, axis=1, keepdims=True)) / (np.std(mfccs, axis=1, keepdims=True) + 1e-10)
    return mfccs
```

### 匹配效果
| 项目 | 平均相关系数 | 可靠度 |
|:----|:----------:|:------|
| 上传编译 | 0.95-0.99 | ✅ 完全可靠 |
| 免密 | 0.87-0.99 | ✅ 完全可靠 |
| 快手（大多数） | 0.95-0.99 | ✅ 完全可靠 |
| 快手（所以模拟器） | 0.47 | ❌ 不可靠，需手动修正 |

### 处理流程
1. 对每个MP3计算MFCC特征
2. 在audio.wav的MFCC上滑动匹配，找最大相关系数的位置
3. 获取MP3的实际时长（ffprobe）
4. 按位置排序，生成精确时间字幕
5. 多行匹配同MP3时，均分该MP3的时长
6. 排序后去重叠（+0.05s间隔）

## 三、VAD 说话检测（备用）

### 工具
- **FunASR fsmn-vad**（`iic/speech_fsmn_vad_zh-cn-16k-common-pytorch`）

### 参数
| 参数 | 值 | 说明 |
|:----|:---:|:-----|
| 合并间距 | 300ms | <300ms的停顿视为连续说话 |

### 局限
- TTS音频音量平坦时检测不准
- 短句可能被遗漏
- **推荐直接使用MFCC声纹匹配，跳过VAD**

## 四、音频拼接顺序

MP3创建时间 ≠ 音频播放顺序
audio.wav的拼接顺序 = 文案顺序（用户手动拼接）

**重要**：MP3文件有相同创建时间时，不要用创建时间排序。
直接用MFCC声纹匹配确定实际音频位置。

## 五、字幕烧录

### FFmpeg注意事项
Windows路径中的 `:`（盘符）会被ffmpeg当成参数分隔符。

**解决方法**：将SRT文件放到沙盒根目录，使用相对路径：
```python
srt_path = 'burnsrt.srt'  # 放在C:\Users\20751\ 用相对路径
subprocess.run([ffmpeg, '-i', video, '-filter_complex', f'subtitles={srt_path}', ...])
```
