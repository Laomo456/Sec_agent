### 关键踩坑：角色名映射
`场景脚本.json` 中speaker为逻辑名（如"9无奈"），
通过 `characters` 映射到实际文件名（如"13双手摊开"）。

**generate.py中必须用 `char_file` 而不是 `char_name` 来拼接图片路径！**
```python
# ✅ 正确
open_img = CHAR_DIR / f"{char_file}张.png"
closed_img = CHAR_DIR / f"{char_file}.png"

# ❌ 错误（找不到图片）
open_img = CHAR_DIR / f"{char_name}张.png"
```


## 三、口型检测

### 最终方案：随机交替法（TTS音频专用）

TTS音频音量平坦，传统阈值法和能量变化率法均无效。
**最终方案**：检测有声/无声 → 有声期间随机交替张嘴闭嘴。

```python
def detect_mouth(db):
    silence_db = np.percentile(db, 15) + 3
    talking = db > silence_db
    
    np.random.seed(42)  # 固定种子保证一致性
    mouth = np.zeros(len(db), dtype=bool)
    i = 0
    while i < len(db):
        if not talking[i]:
            i += 1
            continue
        # 说话期间：张嘴3-8帧，闭嘴1-3帧交替
        for j in range(np.random.randint(3, 9)):
            if i + j < len(db): mouth[i + j] = True
        i += np.random.randint(3, 9)
        i += np.random.randint(1, 4)
    return mouth
```

### 弃用的方案
| 方案 | 问题 |
|:----|:-----|
| 音量阈值法 | TTS音频95%时间张嘴 |
| 能量变化率 | 42%张嘴但抖动不自然 |
| 音频指纹匹配 | TTS混在录屏噪声中无法匹配 |
